Agua 0: La Estructura y la Web Artesanal

Introducción a la construcción web desde el código fuente y las etiquetas básicas

1. HTML como Lenguaje de Estructura

El primer paso en la creación digital independiente consiste en comprender el HTML (HyperText Markup Language) no solo como un formato técnico, sino como el esqueleto lógico de un documento en la red. A diferencia de las plataformas cerradas, escribir etiquetas manualmente permite decidir la jerarquía, el orden y la intención de cada bloque de información.

2. Hojas de Estilo y Presentación Visual

Separar la estructura (HTML) de la apariencia (CSS) es un principio fundamental del diseño web. El archivo CSS otorga identidad tipográfica, ritmo visual y equilibrio de espacios, transformando un texto plano en una experiencia de lectura cómoda y estética.

3. Publicación Abierta y Repositorios

El uso de herramientas como Git y GitHub Pages fomenta el aprendizaje transparente. Al hacer público el código fuente, los sitios web se convierten en proyectos abiertos que pueden ser estudiados, replicados y mejorados colectivamente.
